# NightCoop Manager 0.2.1

## Что это

Небольшая утилита для установки, обновления и удаления мода **NightCoop** для **Cyberpunk 2077**.
Работает как один EXE — ничего дополнительно устанавливать не нужно.

Программа полностью портативная: она **не сохраняет настроек** ни в реестр, ни в свои файлы.
Скачал → установил мод → удалил программу. После неё ничего не остаётся.

## Возможности

- Автоматический поиск папки игры: Steam (реестр и библиотеки), GOG (реестр),
  Epic Games (манифесты лаунчера) и типовые каталоги. Найденная папка проверяется
  по наличию `bin\x64\Cyberpunk2077.exe`
- Ручной выбор папки, если игра установлена в нестандартное место
- Выбор версии игры (2.5 / 2.31) и версии мода
- Установка / обновление / удаление мода
- Проверка доступной версии онлайн
- Бэкап настроек мода (`install-id.txt`, `name.txt`, `servers.txt`)
- Просмотр списка изменений (кнопка «Что нового») для выбранной версии
- Сохранение лога работы программы в файл (по кнопке)
- Три языка интерфейса: русский, английский, шведский

## Как это работает

1. Программа читает `releases.json` с `nightcoop.net` и выбирает сборку, подходящую
   выбранной версии игры (2.5 или 2.31). Если у файла нет ограничения по версии игры,
   он считается совместимым с любой.
2. Скачивает архив выбранной сборки и проверяет контрольную сумму SHA-256.
3. Распаковывает архив и копирует файлы в папку игры.
4. Записывает установленную версию в `red4ext\plugins\NightCoop\version.txt`
   и создаёт манифест установки `.nightcoop-manifest.json` со списком всех
   установленных файлов и их хэшами.

При обновлении программа сначала очищает папку мода `red4ext\plugins\NightCoop\`
от файлов прошлой версии, чтобы не осталось старых DLL. Файлы `install-id.txt`,
`name.txt`, `servers.txt`, логи и папки `backup-*` при этом не трогаются.

**Удаление** работает по манифесту: удаляются только те файлы, которые установила
программа, и только если они не были изменены кем-то другим. Если какой-то файл
уже существовал до установки, он восстанавливается из резервной копии.
Файлы игры, других модов и ваши сохранения не затрагиваются.

## Важно: делай бэкап перед обновлением

В папке `red4ext\plugins\NightCoop\` хранятся важные данные: `install-id.txt`, `name.txt`,
`servers.txt` и файлы логов. В них идентификатор установки и список серверов — то есть
твой прогресс и привязка.

Перед обновлением или удалением нажми **Бэкап настроек**: программа создаст папку
`backup-ДАТА-ВРЕМЯ` и скопирует туда эти файлы, чтобы ничего не потерялось.

Обновление и удаление эти файлы не удаляют, но бэкап всё равно рекомендуется:
он защищает от случайностей и позволяет вернуть данные вручную.

## Лог

Программа ведёт лог текущей сессии во временной папке
`%TEMP%\NightCoopManager\`. Кнопка **Сохранить лог** предлагает сохранить его
в удобное место — например, чтобы приложить к сообщению о проблеме.

## Рекомендации

- Закрывай игру перед установкой или обновлением.
- Ставь ту же сборку мода, что у друзей — для совместной игры версия должна совпадать у всех.
- Если мод не запускается, проверь наличие Red4ext (в архиве NightCoop он уже есть).

## Дисклеймер

Автор этой программы **не связан** с авторами мода NightCoop. Программа написана
для удобства установки и обновления мода и лишь скачивает официальный архив с сайта
`nightcoop.net`, после чего копирует файлы в папку игры.

При любых проблемах с самим модом — он не запускается, вылетает, не подключается к
серверам, вопросы по геймплею или блокировкам — обращайся к **создателям мода и на сайт
nightcoop.net**, а не к автору этой программы.
